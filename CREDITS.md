# Credits

The sound effects in `sfx/` and the particle textures in `fx/` come from the open-source packs listed below. For the web build the sounds were converted to mono MP3 (leading silence trimmed, peak-normalised, long clips shortened with a fade) and the textures were scaled down with their brightness turned into transparency; the listed file names point at the originals.
Every one of these packs is released under CC0 1.0 (public domain dedication), so attribution is not required; it is given here anyway as thanks and as a record of where each file came from.

`sfx/`와 `fx/` 폴더의 효과음과 파티클 이미지는 아래 오픈소스 팩(모두 CC0 1.0)에서 가져와, 웹용으로 변환(MP3 모노·앞 무음 제거·음량 정규화 / 이미지 축소·밝기를 투명도로)한 것입니다.
